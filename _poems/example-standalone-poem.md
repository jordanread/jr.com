To keep line breaks in a stanza, end each line with two trailing
spaces —  
like this,  
so Markdown renders a real line break instead of joining everything
into one paragraph.

A blank line between stanzas still works exactly like normal
Markdown paragraphs.

---

This one has no `series` field, so it shows up under "Poems" on
`/poetry/`, not inside a collection.
