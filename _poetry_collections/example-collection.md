intro, the story behind the collection, whatever fits. It's fine to
leave this blank too; the poem list still renders either way.

This file's name (`example-collection.md`, so slug `example-collection`)
is the identifier poems reference in their own `series:` front matter
field to join this collection — there's no separate ID to keep in
sync manually. Rename this file and update the matching poems'
`series:` value together if you ever need to change the slug.
